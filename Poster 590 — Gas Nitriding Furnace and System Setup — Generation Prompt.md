## Phase 4 -- Furnace Types (HERO)

Y: 2.9" to 14.5". Section label: `FURNACE TYPES FOR GAS NITRIDING`. 3 tall cards:

**PIT FURNACE (`#27AE60`, MOST COMMON):** Vertical retort sunk in floor; parts hang from top; gravity + fan circulation; load dia 24--72 in; best for shafts, gears, dies, landing gear.

**BELL FURNACE (`#E8A020`):** Parts on base plate; bell lowered over; sealed at base; easy floor-level loading; good for heavy/large components; multiple bases.

**HORIZONTAL RETORT (`#2EC4B6`):** Tray-loaded; pushed in on rails; familiar loading; good for mixed small parts; flat parts = contact risk; gas circulation less uniform.

Note: `Continuous furnaces are rare for gas nitriding -- batch processing dominates due to 15--90+ hour cycles.`

## Phase 5 -- AMS 2750 + Atmosphere System

### AMS 2750 (Y: 14.5"--19.5")

Section label: `AMS 2750 PYROMETRY -- TEMPERATURE UNIFORMITY`.

**Left -- Class Table:** Class 2 (+/-10 F, precision aerospace) | Class 3 (+/-15 F, standard) | Class 4 (+/-20 F, general). Nitriding typically Class 2 or 3.

**Right -- Instrumentation:** Type A/B per AMS 2750; recording instrument mandatory; SAT per schedule; TUS quarterly/semiannual; load TC required; Type J/K/N standard.

### Atmosphere System (Y: 19.5"--27.5")

Section label: `ATMOSPHERE SYSTEM -- AMMONIA SUPPLY & EXHAUST`. 6 component cards (3x2):

| Component | Content |
|---|---|
| NH3 SUPPLY | Anhydrous from cylinders (150 lb) or bulk; store upright, chained; no copper fittings |
| FLOW CONTROL | Rotameter or MFC; set to maintain target dissociation; adjusted per furnace volume |
| DISSOCIATOR (OPTIONAL) | Pre-dissociates NH3; fine-tunes KN in controlled-potential systems per AMS 2759/10 |
| INTERNAL FAN | Circulates NH3; critical for uniform case; fan failure = uneven case |
| EXHAUST / BURN-OFF (`#E05C5C`) | H2 + N2 + NH3 exits; burn-off pilot MANDATORY; pilot failure = explosion risk |
| DISSOCIATION MEASUREMENT | Burette method or H2 sensor + NH3 analyzer for real-time KN |

## Phase 6 -- Pre-Cycle Checks

Y: 27.5"--32.5". Section label: `PRE-CYCLE SETUP VERIFICATION`. 4 cards:

| Check | Detail |
|---|---|
| BURN-OFF PILOT | Verify lit; check flame sensor interlock; NEVER introduce NH3 with pilot out |
| SEAL INTEGRITY | Retort gasket sealed; leak check; air infiltration during 40+ hr oxidizes parts |
| FAN OPERATION | Verify running; check amperage; failure mid-cycle = uneven case |
