## Phase 5 -- Hardness Testing

Y: 15.5" to 22.0". Section label: `HARDNESS TESTING -- GET IT RIGHT`.

**Left -- WHY HRC DOES NOT WORK (`#E05C5C`):** 150 kgf penetrates 0.003--0.005 in; typical case only 0.005--0.025 in; reads THROUGH case into soft core; falsely low. NEVER use for spec compliance.

**Right -- USE MICROHARDNESS (`#27AE60`):** Vickers/Knoop 300--500 gf; indentation < 0.0005 in -- stays in case; traverse at 0.001--0.002 in steps; plot HV vs. depth; ECD = depth to core + 50 HV. Rockwell 15N acceptable for production screening -- correlate to HV.
