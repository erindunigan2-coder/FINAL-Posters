## Phase 5 -- Bath Chemistry + Temperature Gauge

Y: 14.5" to 20.5". Section: `BATH CHEMISTRY + THE CRITICAL TEMPERATURE WINDOW`.

**Left -- Three-component breakdown (Y: 15.3" to 18.5"):**
- NaOH (accent `#2EC4B6`): 600--900 g/L -- dissolves iron; maintains alkalinity; primary constituent
- NaNO2 (accent `#E8A020`): 30--75 g/L -- primary oxidizer; converts Fe2+ to Fe3+ for magnetite
- NaNO3 (accent `#E8A020`): 30--75 g/L -- secondary oxidizer; temperature stabilizer

**Right -- Temperature Gauge:**

| Zone | Temp | Color | Label |
|---|---|---|---|
| Danger (top) | > 300 F | `#E05C5C` | Salts out; crystallization |
| OPTIMAL | 280--295 F | `#27AE60` | BLACK MAGNETITE |
| Warning | 275--280 F | `#E8A020` | Marginal -- risk of red |
| Danger (bottom) | < 275 F | `#E05C5C` | RED ROUGE (Fe2O3) |

Optimal marker at 285 F.

**Chemistry summary (full width, Y: 19.0"):**
`Fe + 2NaOH --> Na2FeO2 + H2 | 3Na2FeO2 + NaNO2 + 2H2O --> Fe3O4 + 7NaOH + NH3` in JetBrains Mono.

## Phase 6 -- Defect Diagnosis Grid

Y: 20.5" to 26.5". Section: `WHAT GOES WRONG -- 5 COMMON DEFECTS`.

3 top + 2 bottom centered:

| Defect | Cause | Fix |
|---|---|---|
| RED / BROWN OXIDE | Bath temp < 275 F; depleted NaNO2; diluted bath | Increase temp; add NaNO2; check SG |
| SMUTTY / RUBS OFF | Bath too hot (> 300 F); over-immersion; depleted NaOH | Cool bath; reduce time; add NaOH |
| NON-UNIFORM / SPOTS | Oil contamination; parts touching; poor cleaning | Improve cleaning; rearrange load |
| RUSTING AFTER BLACK | No oil seal; caustic residue; insufficient rinse | Oil immediately; improve rinse |
| RED FINGERPRINTS | Handling before oil seal; localized contamination | Gloves always; no bare-hand contact |

## Phase 7 -- Film Characteristics + MIL Spec

Y: 26.5" to 32.5". Section: `MAGNETITE FILM -- WHAT YOU GET`.

**Left -- Film Properties:**

| Property | Value |
|---|---|
| Composition | Fe3O4 (magnetite -- inverse spinel) |

| Class | Description |
|---|---|

| Class 2 | Room temperature (NOT recommended) |
