## Phase 6 -- Acid vs. Alkaline Copper

Y: 22.0" to 28.5". Section: `ACID VS. ALKALINE COPPER -- WHEN TO USE EACH`.

**Left -- Acid Copper Sulfate:**
Accent `#27AE60`. Subtitle: `The Bright Workhorse`.

| Property | Value |
|---|---|
| pH | -- (strongly acidic, not measured) |
| Copper source | CuSO4-5H2O |
| Temperature | 70--80 F |
| Brightness | Excellent -- mirror-bright from bath |
| Leveling | Exceptional with proper additives |
| Throwing power | Moderate |
| Substrates | Cu, brass, nickel, steel (with strike) |
| Speed | High -- near 100% cathode efficiency |
| Typical use | Decorative, PCBs, electroforming |

Bottom: `Cannot plate directly on steel or zinc -- immersion deposit will peel. Strike required.` -- `#27AE60`

**Right -- Alkaline Non-Cyanide Copper:**
Accent `#E8A020`. Subtitle: `The Strike Alternative`.

| Property | Value |
|---|---|
| pH | 8--11 |
| Copper source | CuSO4 + complexant (HEDP, citrate) |
| Temperature | 110--145 F |
| Brightness | Matte to semi-bright |
| Throwing power | Good -- better than acid |
| Substrates | Steel, zinc die cast, ABS (direct) |
| Speed | Lower -- 40--70% cathode efficiency |
| Typical use | Strike layer before acid copper |

Bottom: `Cyanide-free strike for active metals -- plates directly on zinc die castings and steel.` -- `#E8A020`

## Phase 7 -- Troubleshooting

Y: 28.5" to 32.5". Section: `QUICK TROUBLESHOOTING -- 4 COMMON PROBLEMS`.

| Problem | Cause | Fix |
|---|---|---|
| HAZY/MILKY DEPOSIT | Low Cl- (<30 ppm) or organic contamination | Check Cl- by titration; carbon treat |
| PITTING | Oil drag-in, low carrier, poor agitation | Improve cleaning; add carrier; increase air |
| ROUGHNESS | Anode sludge, no anode bags, particulate | Install PP anode bags; increase filtration |
| BURNING AT HCD | CD too high, low copper metal, high acid | Reduce CD; add CuSO4; check acid:Cu ratio |
