## Phase 4 -- Inspection Test Matrix (HERO)

### 7-Row Test Matrix

Full width. Columns: Test (3.5") | Method/Standard (5.0") | Acceptance Criteria (7.0") | Notes (7.5").

| Test | Method | Acceptance Criteria | Notes |
|---|---|---|---|
| Bond strength | ASTM C633 (tensile adhesion) | > 80 MPa (reports "> epoxy strength") | Bond exceeds 70--80 MPa FM1000 epoxy |
| Porosity | ASTM E2109 (image analysis) | < 1.0% (typ <0.5%; often <0.2%) | Lowest porosity of any thermal spray |
| Thickness | Eddy current / mag-gauge / ASTM B487 | Per drawing +/- 25 um | Tighter than HVOF (+/- 50 um) |
| Hardness | ASTM E384 (HV300) | 1200--1500 HV300 (WC-12Co) | Min 5 indentations across cross-section |
| Surface roughness | Profilometer (Ra) | Ground: Ra <0.4 um; superfinished: <0.1 um | As-sprayed Ra 2--5 um for reference only |
| Microstructure | Metallographic cross-section | Uniform carbide; no oxide stringers; no delamination | SEM recommended for detailed carbide eval |
| Visual | Unaided eye + 10x loupe | No spalling, blistering, orange peel, bare spots | Before and after grinding |

Header fill `#3A4055`. ASTM numbers in `#E8A020`.

### Metallographic Cross-Section Guide

Two side-by-side panels:

**Good (emerald accent):** Uniform WC distribution. No continuous oxide stringers. Porosity <0.5% isolated round pores. Minimal decarburization (angular WC morphology). Clean interface. Carbides retain original size.

**Rejectable (coral accent):** Oxide stringers as dark lines between splats. Decarburized zones (rounded WC; eta-phase W2C or W). Porosity >1% or interconnected. Interface voids/contamination. Banded structure. Hardness below 1200 HV.

## Phase 6 -- Test Coupons + Reject Criteria

### Test Coupon Protocol (Y: 22.0"--28.5")

Section label: `DESTRUCTIVE TEST COUPONS -- SPRAY WITH EVERY BATCH`.

**Left -- 6-Step Procedure (W: 14.0"):**

| Step | Accent | Action | Detail |
|---|---|---|---|
| 1 | `#E8A020` | PREPARE COUPONS | Same substrate; grit-blasted identically; min 2 per batch |
| 2 | `#2EC4B6` | MOUNT IN BOOTH | Adjacent to production parts; same standoff/angle |
| 3 | `#27AE60` | SPRAY SIMULTANEOUSLY | Identical coating; same params, operator, session |
| 4 | `#E8A020` | GRIND IDENTICALLY | Same wheel, coolant, infeed as production |
| 5 | `#2EC4B6` | DESTRUCTIVE TEST | Section for metallography/hardness; C633 bond; E2109 porosity |
| 6 | `#27AE60` | CORRELATE TO PRODUCTION | Coupon results = production coating quality. If fail, parts suspect. |

**Right -- Why Coupons? (W: 8.5")**

Emerald-accented glass card. D-Gun parts are high-value aerospace -- cannot be destructively tested. Coupons sprayed alongside provide data without sacrificing the part. Required by most D-Gun specs.

`1 coupon = 1 C633 pull + 1 cross-section (porosity + hardness + microstructure). Min 2 per batch.`

### Reject Criteria (Y: 28.5"--32.5")

Section label: `REJECT CONDITIONS`. Four cards, coral accent:

| Condition | Action |
|---|---|
| POROSITY > 1% | Strip by blast; investigate gas ratios, charge, barrel; re-spray after root cause |
| HARDNESS < 1200 HV300 | Decarburization -- ratio too fuel-rich; verify metering; strip and re-spray |
| BOND BELOW SPEC | Investigate prep (contamination, stale blast); re-blast and re-spray |
| THICKNESS OUTSIDE TOL | Below min: strip and re-spray with allowance. Above max: additional grinding if min maintained. |
