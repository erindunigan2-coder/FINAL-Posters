## Phase 5 -- Startup Sequence

Y: 15.5" to 22.0". Section label: `STARTUP SEQUENCE -- DOOR CLOSED TO PLASMA ON`. 8 steps:

| Step | Action | Parameter | Check |
|---|---|---|---|
| 1 | Close/seal door | O-ring integrity | Visual inspect |
| 2 | Start rough pump | < 10 mbar | Monitor gauge |
| 3 | Engage Roots blower | < 0.1 mbar | Leak rate < 1 mbar/min |
| 4 | Leak rate test | Hold vacuum | FAIL if > 1 mbar/min rise |
| 5 | H2 flush | Low flow purge | 2--5 min |
| 6 | Set gas ratio | N2/H2 per recipe (25/75) | Verify MFC |
| 7 | Set pressure | Throttle to 1--5 mbar | Stable pressure |
| 8 | Energize DC | Low voltage ramp up | Uniform glow; adjust pulse |

## Phase 6 -- Glow Interpretation + Parameter Windows

### Plasma Glow Guide (Y: 22.0"--32.5", left)

Section label: `READING THE GLOW`. 4 indicator cards:

| Glow State | Color | Meaning | Action |
|---|---|---|---|
| Uniform violet/purple | `#27AE60` | Normal | Proceed |
| Bright spots | `#E05C5C` | Hollow cathode arcing | Reduce voltage; check spacing |
| Dim/patchy | `#E8A020` | Low pressure or voltage | Increase voltage/pressure |
| No glow | `#E05C5C` | Plasma not ignited | Check DC supply; verify pressure |

### Operating Windows (right)

Section label: `OPERATING WINDOWS`. 9-row table:

| Parameter | Typical Range | Notes |
|---|---|---|
| Base vacuum | < 0.1 mbar | Before gas intro |
| Operating pressure | 1--5 mbar | Throttle valve |
| DC voltage | 400--800 V (pulsed) | Pulsed preferred |
| Pulse frequency | 1--10 kHz | Higher = finer control |
| Duty cycle | 20--80% | Controls power/temp |
| N2 fraction | 5--80% | 25% standard; low = no WL |
| H2 fraction | 20--95% | Balance of N2 |
| Current density | 0.5--3.0 mA/cm2 | On cathode area |
| Supplemental heat | As needed | Resistance heaters |
