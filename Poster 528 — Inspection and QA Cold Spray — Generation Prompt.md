## Phase 4 -- Material-Specific Criteria

Y: 14.0" to 22.0". Section label: `ACCEPTANCE CRITERIA BY MATERIAL`.

Three side-by-side material cards (W: 7.3" each, H: 6.5"):

**Card 1 -- COPPER (accent `#E8A020`):**

| Property | Criteria |
|---|---|
| Bond strength | > 40 MPa (often > epoxy) |
| Porosity | < 0.5% |
| Hardness (as-sprayed) | 100--150 HV |
| Hardness (annealed) | 60--90 HV |
| Conductivity (as-sprayed) | > 80% IACS |
| Conductivity (annealed) | > 95% IACS |

Note: `Benchmark cold spray material. Near-bulk properties achievable.`

**Card 2 -- ALUMINUM (accent `#2EC4B6`):**

| Property | Criteria |
|---|---|
| Bond strength | > 30 MPa |
| Porosity | 0.5--2% |
| Hardness | 80--130 HV (alloy-dependent) |
| Temper | Per alloy spec (T6, T7) |
| Visual | No delamination at repair interface |
| Tensile (E8) | > 80% of wrought (post-anneal) |

Note: `Primary aerospace repair material. MIL-STD-3021 compliance for defense.`

**Card 3 -- TITANIUM (accent `#27AE60`):**

| Property | Criteria |
|---|---|
| Bond strength | > 30 MPa |
| Porosity | 1--3% |
| Hardness | 250--400 HV |
| Oxygen content | Monitor -- anneal atmosphere critical |
| Microstructure | Severe deformation; good inter-particle bonding |
| Anneal | Vacuum mandatory; 500--700 C |

Note: `Requires He carrier gas. N2 alone insufficient for Ti and Ti-6Al-4V.`

## Phase 5 -- Metallography + Reject Criteria + Footer

**Left -- Cross-Section Guide (W: 12.0"):**

Section label: `METALLOGRAPHIC CROSS-SECTION -- WHAT TO LOOK FOR`.

6 feature cards. Good in `#27AE60`, Bad in `#E05C5C`.

| Feature | Good | Bad |
|---|---|---|
| Particle deformation | Pancake-shaped (high velocity) | Round particles (insufficient velocity) |
| Interface quality | Continuous contact, no voids | Gaps or oxide film at interface |
| Porosity distribution | Rare, isolated pores | Connected porosity channels |
| Inter-particle bonding | Minimal contrast at boundaries | Visible gaps between particles |
| Oxide inclusions | None (virtually absent in CS) | Any oxide layer = process problem |
| Coating uniformity | Consistent thickness | Thin spots or density variations |

**Right -- Reject Criteria (W: 10.5"):**

Section label: `COMMON REJECTION REASONS`.

5 reject cards:

| Rejection | Color | Root Cause |
|---|---|---|
| BOND STRENGTH BELOW SPEC | `#E05C5C` | Contamination; insufficient velocity; excessive blast-to-spray time |
| POROSITY ABOVE SPEC | `#E05C5C` | Velocity too low; wrong powder morphology |
| HARDNESS OUT OF RANGE | `#E8A020` | Anneal schedule incorrect; verify time/temp/atmosphere |
| BARE SPOTS / DELAMINATION | `#E05C5C` | Masking error; nozzle clog; contaminated substrate |
| CONDUCTIVITY BELOW TARGET | `#E8A020` | Anneal not performed or insufficient; high porosity |
