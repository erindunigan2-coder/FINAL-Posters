## Phase 5 -- Hardness + Porosity Reference

Y: 15.5" to 22.0". Section label: `EXPECTED HARDNESS BY COATING MATERIAL`.

**Left -- Hardness (W: 11.0"):**

| Coating | Hardness (HV300) | Notes |
|---|---|---|
| Alumina (Al2O3) | 800-1,200 | General ceramic wear |
| Chrome oxide (Cr2O3) | 1,000-1,800 | Hardest APS ceramic |
| YSZ (7-8% Y2O3) | 600-900 | TBC topcoat |
| NiCr (80/20) | 250-400 | Metallic wear/corrosion |
| MCrAlY | 300-500 | TBC bond coat |

**Right -- Porosity Targets (W: 11.5"):**

| Application | Target Porosity | Why |
|---|---|---|
| TBC (thermal barrier) | 10-20% | Strain tolerance + thermal insulation |
| Wear coating (Al2O3, Cr2O3) | < 5% | Low porosity = wear resistance |
| Abradable | 30-60% | Must wear away on contact |
| Metallic corrosion | < 5% (+ seal) | Seal porosity for corrosion barrier |

## Phase 6 -- Microstructure Guide + Accept/Reject

### Microstructure Guide (Y: 22.0"-28.5")

Section label: `READING THE CROSS-SECTION -- WHAT TO LOOK FOR`. 3x2 grid of cards:

| Feature | Good Sign | Bad Sign |
|---|---|---|
| Splat structure | Flat, well-deformed lamellae | Round, unmelted particles |
| Interface | Clean bond line; profile visible | Gaps, contamination at interface |
| Porosity distribution | Uniform, fine pores (if expected) | Large interconnected voids |
| Oxide content | Minimal dark stringers | Heavy oxide layers between every splat |
| Cracks | None (or controlled vertical in TBCs) | Horizontal cracks parallel to interface |
| Thickness uniformity | Consistent across section | Thinning at edges or high points |

Good: `#27AE60`. Bad: `#E05C5C`.

### Accept/Reject (Y: 28.5"-32.5")

**Left -- ACCEPT (Emerald):** fill `#27AE60` at 12%. All tests meet spec. Visual passes. Documentation complete (coupons, parameter logs, certs).

**Right -- REJECT/REWORK (Coral):** fill `#E05C5C` at 12%. Any test below spec. Strip and re-spray (most common). Root cause analysis before re-spray. `Never ship a marginal coating -- the failure will be more expensive than the rework.`
