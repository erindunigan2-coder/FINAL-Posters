**Box contents:**

*Box 1 -- Alkaline Clean:* `130--160 F` / `30--60 g/L` / `2--10 min`. Check: `EVEN MORE CRITICAL for hardcoat -- defects amplified by thick coating`

*Box 2 -- Rinse (Pre-Etch):* `Ambient` / `Cascade preferred`. Same as Type II.

*Box 3 -- Etch (LIGHT OR NONE):* `Full: NaOH 40--80 g/L, 1--3 min` / `Light: NaOH 20--40 g/L, 30--60 sec` / `None: skip to desmut`. Check: `PRECISION PARTS: skip etch -- caustic removes 0.5--1.0 mil/min` `#E05C5C`

*Box 4 -- Desmut:* `HNO3 25--50%` / `HF for Cu alloys` / `Ambient, 30--180 sec`. Check: `Trapped smut under hard coat = delamination` `#E05C5C`

*Box 5 -- Rinse (Pre-Anodize):* `DI water, triple cascade` / `<100 uS/cm target`. Check: `F- dragover amplified at hard coat CD -- catastrophic pitting` `#E05C5C`

*Box 6 -- Hard Anodize:* `H2SO4 150--200 g/L` / `28--41 F (0--5 C) -- REFRIGERATION` / `24--36 ASF (ramp up!)` / `30--120 min`. Check: `TEMPERATURE IS EVERYTHING -- chiller required` `#E8A020`

*Box 7 -- Rinse (Post-Anodize):* `DI water preferred` / `Remove residual acid`. Standard.

*Box 8 -- Seal:* `Hot DI: 205--212 F, 20+ min` / `Ni acetate: 167--185 F` / `PTFE: for low friction`. Check: `PTFE seal: CoF drops from 0.4--0.6 to 0.08--0.15`

## Phase 7 -- Troubleshooting

Y: 28.5" to 32.5". Section: `QUICK TROUBLESHOOTING -- 4 COMMON PROBLEMS`.

| # | Problem | Cause | Fix |
|---|---|---|---|
| 1 | BURNING | Excessive CD, no current ramp, sharp edges | Use ramp protocol; round edges; reduce CD |
| 2 | CRACKING / SPALLING | Thickness exceeds alloy limit; trapped smut | Stay within alloy limits; improve desmut |
| 3 | POWDERING | Temperature >41 F (>5 C) | STOP; check chiller; cool bath |
| 4 | NON-UNIFORM THICKNESS | Inadequate agitation; heat buildup zones | Increase agitation; check for dead spots |
