## Phase 5 -- Dual Chemistry Panels

Y: 14.5" to 20.5". Section: `BATH CHEMISTRY -- TRIVALENT VS. HEXAVALENT`.

**Left -- Trivalent (Cr III):**
Accent `#27AE60`. Badge: `CURRENT STANDARD`.

| Component | Range | Optimal |
|---|---|---|
| Chromium (Cr3+) | 4--8 g/L | 5--6 g/L |
| Complexant | Per supplier TDS | Per supplier |
| Conductivity salt | NaCl, NH4Cl, or KCl | Per supplier |
| pH | 2.5--4.0 | 3.0--3.5 |
| Temperature | 80--120 F | 95--110 F |
| CD | 50--200 ASF | 80--150 ASF |
| Efficiency | 15--30% | 20--25% |
| Thickness | 0.15--0.50 um | 0.3 um |

Bottom: `RoHS/REACH compliant. No Cr(VI) mist. Safer bath chemistry.` -- `#27AE60`

**Right -- Hexavalent (Cr VI):**
Accent `#E05C5C`. Badge: `LEGACY -- RESTRICTED`.

| Component | Range | Optimal |
|---|---|---|
| CrO3 | 200--400 g/L | 250--300 g/L |
| H2SO4 (catalyst) | CrO3:SO4 = 100:1 | Ratio 100:1 |
| Sulfate (SO4) | 2.0--4.0 g/L | 2.5--3.0 g/L |
| Temperature | 95--120 F | 105--115 F |
| CD | 100--300 ASF | 150--200 ASF |
| Efficiency | 10--18% | 12--15% |
| Thickness | 0.25--0.75 um | 0.5 um |
| Cr3+ limit | < 5 g/L operating | Monitor; dummy plate to reduce |

Bottom: `OSHA PEL 5 ug/m3. Known carcinogen. RoHS/REACH restricted.` -- `#E05C5C`

## Phase 6 -- Bright Range + Defect Grid

Y: 20.5" to 26.5". Section: `THE BRIGHT RANGE + WHAT GOES WRONG`.

**Left -- Temperature-CD Bright Range (W: 11.0"):**
Simplified chart: Y-axis = CD (ASF), X-axis = Temperature (F). Three zones: `BURNED` (top-left, coral) | `BRIGHT RANGE` (center diagonal, emerald) | `DULL / MILKY` (bottom-right, slate). Note: `The bright range is a narrow diagonal band. Higher temp needs higher CD. A 5 F shift can change everything.`

**Right -- 6 Common Defects (W: 11.5"):**
3x2 grid, compact cards:

| Defect | Cause | Fix |
|---|---|---|
| DULL/MILKY | CrO3:SO4 off, Cr3+ high | Check ratio; dummy plate |
| BURNING | CD too high for temp | Reduce CD; check racking |
| PEELING | Nickel passivated | Improve activation |
| NO LCD COVERAGE | Poor throwing power | Improve racking; thieves |
| PITTING | Ni pitting transferred | Fix nickel first |
| HEX MIST | No fume suppressant | Add PFOS-free suppressant |

## Phase 7 -- Anode Config + Safety

Y: 26.5" to 32.5".

**Left -- Anode Configuration (W: 14.0"):**

| Parameter | Hexavalent | Trivalent |
|---|---|---|
| Anode type | Lead or Pb-Sn alloy (93:7) | Graphite or MMO on Ti |
| A:C ratio | 1:1 to 2:1 | 1:1 to 2:1 |
| Solubility | Insoluble | Insoluble |
| Cr replenishment | CrO3 addition | Cr3+ salt addition |
| Anode film (hex) | PbO2 -- oxidizes Cr3+ back to Cr6+ | N/A |

Note: `Lead anodes in hex baths develop a PbO2 film that maintains Cr6+/Cr3+ balance. Do not scrub this film off.` -- `#E8A020`

**Right -- Safety & Regulatory (W: 8.5"):**
Coral-bordered panel:
- Cr(VI) = KNOWN HUMAN CARCINOGEN (IARC Group 1)
- OSHA PEL: 5 ug/m3 (8-hr TWA)
- Enclosed ventilation REQUIRED
- Chemical fume suppressants (PFOS-free)
- Respiratory protection program
- Chromic acid = powerful oxidizer: fire risk with organics
- Severe burns and chrome ulcers from skin contact
- Lead anodes: PPE during maintenance

Regulatory: RoHS restricted | REACH Annex XIV | Automotive OEMs mandate trivalent.
