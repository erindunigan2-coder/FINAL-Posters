## Phase 5 -- Alkaline Contamination

Y: 14.5" to 20.5". Section: `WHAT ALKALINE DRAG-IN DOES TO YOUR CHROME BATH`.

Full-width panel, accent `#E05C5C`:

| Contaminant | Effect | Severity |
|---|---|---|
| NaOH (caustic) | Raises pH; precipitates Cr(OH)3 sludge; reduces CrO3 | HIGH |
| Surfactant | Organic contamination -- reduced efficiency, pitting | HIGH |
| Silicate | Insoluble silica deposits -- rough chrome | MODERATE |
| Hard water minerals | Calcium/magnesium buildup | LOW |

Key insight: `Chrome baths are long-lived (months to years). Every contamination event is cumulative. Good rinsing protects bath lifespan.` -- `#E8A020`

Cleaner selection: `Use silicate-free cleaners when possible. Silicate residue is nearly impossible to remove from a chrome bath.` -- `#E05C5C`

| Parameter | Rinse 1 (Rough) | Rinse 2 (Final) |
|---|---|---|
| Water source | City water | DI preferred |
| Temperature | Ambient | Ambient |
| Type | Continuous overflow | Continuous overflow |
| Dwell time | 30--60 sec | 30--60 sec |
| Flow rate | Moderate-high | Moderate |
| Agitation | 2--3 dips | 2--3 dips |
| Conductivity | Not critical | < 200 uS/cm |
| Maintenance | Dump when contaminated | Monitor conductivity |

Bottom: `Total rinse time: 1--2 min. Longer than decorative chrome rinsing (15--30 sec) because alkaline contamination is cumulative and expensive to correct.` -- `#2EC4B6`
