# Poster #104 -- Construction Workup
## Cleaning -- Copper (Alkaline)

*Alaina -- Plating Posters Inc Creative Lead*
*v1.0 -- 2026-04-26*

Stage 1 of the alkaline non-cyanide copper process. The cleaning requirements here are especially demanding because this process is typically used on difficult substrates -- zinc die castings (porosity, machining oils trapped in pores), steel (mill scale, rust preventatives), and ABS plastic (mold release agents). Each substrate has its own cleaning challenge.

For zinc die castings, electrocleaning must be cathodic only -- anodic electrocleaning would dissolve the zinc. For steel, the standard soak + electroclean sequence applies. For ABS plastic, cleaning is done during the pre-metallization sequence (etch, neutralize, activate, electroless) which is outside the scope of this poster.

Hero visual: tank cross-section with substrate-specific callouts.

### ZONE 4 -- Parameter Tables

**Section label:** `CLEANING PARAMETERS -- DETAILED` -- Y: 14.7".

**Left table -- Soak Clean (X: 0.5", W: 11.0"):**

| Parameter | Value |
|---|---|
| Cleaner type | Alkaline soak (per supplier TDS) |
| Concentration | 4--8 oz/gal (30--60 g/L) |
| Temperature | 140--180 F (60--82 C) |
| Time | 3--10 min (zinc DC may need 5--15 min) |
| Agitation | Mechanical, air, or ultrasonic |
| pH | 11--13 |
| Note | Non-silicated preferred (silicate films cause adhesion failure) |

**Right table -- Electroclean (X: 12.0", W: 11.5"):**

| Parameter | Value |
|---|---|
| Type -- Steel | Cathodic then anodic (standard) |
| Type -- Zinc DC | CATHODIC ONLY (anodic dissolves zinc) |
| Current density | 5--10 ASF (zinc DC); 20--50 ASF (steel) |
| Temperature | 140--180 F (60--82 C) |
| Time | 30--60 sec each direction (steel); 30--60 sec cathodic only (zinc DC) |
| Benefit | Removes embedded soils, improves adhesion |
| Caution | Cathodic: H2 evolution -- H-embrittlement on high-strength steel |
| Key rule | Never anodic on zinc die castings -- ever |

**Section label:** `SUBSTRATE-SPECIFIC CLEANING CHALLENGES` -- Y: 21.2".

**BLOCK E -- Three Substrate Cards (Y: 21.8" to 24.5")**

| Card | X | W | Accent | Substrate | Key Challenge |
|---|---|---|---|---|---|
| 1 | 0.5" | 7.33" | `#E8A020` | `ZINC DIE CAST` | Porosity traps oil. Ultrasonic recommended. Cathodic EC only. Do NOT over-clean -- zinc is reactive. |
| 2 | 8.17" | 7.33" | `#2EC4B6` | `STEEL` | Mill scale, rust preventatives, drawing compounds. Standard soak + anodic EC works well. |
| 3 | 15.83" | 7.67" | `#27AE60` | `BRASS` | Light oils and tarnish. Moderate cleaning sufficient. Non-silicated cleaner preferred. |

**BLOCK F -- Problem Table (Y: 25.0" to 26.8")**

| Problem | Symptom Downstream | Root Cause | Fix |
|---|---|---|---|
| Water break | Poor adhesion, skip plating | Residual oil -- cleaner weak or cold | Increase temp/time; add ultrasonic (zinc DC) |
| Zinc dissolution | Pitting, rough surface on zinc DC | Anodic electrocleaning or over-cleaning | Switch to cathodic only; reduce EC time |
| Embedded metals | Rough copper deposit | Cathodic EC embedding Fe or other metals | Use anodic EC as final step (steel only) |
| Cleaner film | Skip plating, haze | Silicate residue from cleaner | Switch to non-silicated cleaner |

## Design Notes

The unique angle for this cleaning poster is the zinc die casting substrate. Zinc DC cleaning is the hardest pre-treatment in the copper line because porosity, the reactive nature of zinc (cannot anodic electroclean), and the tight activation window all compound. The cathodic-only electroclean rule is prominently placed because getting this wrong destroys the substrate.
