## Phase 5 -- Fuse Verification + Documentation

### Fuse Quality Verification (Y: 15.5"-22.0")

Section label: `FUSED COATING VERIFICATION -- SELF-FLUXING ALLOYS`. Three panels.

**VISUAL "SWEAT" TEST (accent `#E8A020`):** Surface transitions matte to glossy during fuse. PASS: entire surface uniform gloss. FAIL: patchy matte areas = incomplete fusion. Operator judgment -- experience matters.

**METALLOGRAPHIC CROSS-SECTION (accent `#2EC4B6`):** Cut, mount, polish test coupon. 100-500x magnification. PASS: fully wetted interface, <2% porosity, no unfused zones. FAIL: visible interface line, residual porosity >2%.

**HARDNESS CHECK (accent `#27AE60`):** Vickers HV300 on polished cross-section. As-sprayed: 300-500 HV. Properly fused: 700-900 HV. Below 600 HV = incomplete fusion -- re-fuse or investigate. Minimum 5 indentations across thickness.

### Documentation Checklist (Y: 22.0"-28.5")

Section label: `QA DOCUMENTATION REQUIREMENTS`. 9-item checklist, 2 columns.

| Item | Record |
|---|---|
| Feedstock material and lot number | CoC from supplier |
| Pre-spray surface prep | Media type, grit size, Ra, cleanliness standard |
| Spray parameters | Gas pressures, feed rate, standoff, traverse speed |
| In-process thickness | Readings at multiple locations vs. target |
| Substrate temperature log | Peak temp; cooling interventions |
| Post-treatment performed | Seal type/time, fuse temp/method, or machining spec |
| Final inspection results | Bond, porosity, thickness, hardness, visual |
| Operator identification | Spray operator and inspector name/ID |
| Date and time stamps | Each process step |

Below: `Good documentation is your evidence that the process was followed. If it is not recorded, it did not happen.` `#2EC4B6`.

## Phase 6 -- Reject Criteria

Y: 28.5" to 32.5". Section label: `REJECT CONDITIONS -- STRIP AND RE-SPRAY`. Four cards, accent `#E05C5C`.

| Condition | Action |
|---|---|
| BOND STRENGTH BELOW MINIMUM | Strip by grit blast or chemical; investigate root cause; re-blast and re-spray |
| POROSITY EXCEEDS SPEC | If sealable, seal and retest; if <2% required and at 5-15%, fusing was needed |
| DELAMINATION OR BLISTERING | Strip completely; do not spray over; investigate interface contamination or overheating |
| INCOMPLETE FUSING | Re-fuse if substrate tolerates second cycle; if not, strip and re-spray with proper procedure |
