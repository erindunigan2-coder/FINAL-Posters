## Phase 5 -- Current Distribution + Anode Setup

Y: 14.5" to 22.0". Two-column layout.

**Left -- CURRENT DISTRIBUTION (`#E05C5C` accent):**

```
PROBLEM: Current follows path of least resistance.
Edges/corners/protrusions = highest CD = thickest deposit.
Recesses = lowest CD = thinnest.
A 5 mm target can vary 8 mm (edge) to 2 mm (recess) without management.

SOLUTIONS:
1. CONFORMING ANODES -- constant A-C distance
2. SHIELDS (non-conductive) -- block current at high-CD areas
3. THIEVES (aux. cathodes) -- draw current from edges
4. A-C DISTANCE -- 100-200 mm general rule
```

**Right -- ANODE TYPES (`#27AE60`):**

| Anode Type | Material | Application | Notes |
|---|---|---|---|
| S-depolarized Ni rounds | Electrolytic Ni, S-activated | Ni sulfamate EF | Standard; 99.5%+ purity |
| Ni crowns/bars | Cast or rolled Ni | Ni Watts EF | Less common |
| OFHC copper | Oxygen-free high-conductivity | Acid Cu EF | Phosphorized for stability |
| Ti baskets | Titanium mesh | All EF baths | Fill with Ni rounds or Cu chips; bags required |
| Insoluble (Pt/Ti, MMO) | Platinum-clad Ti | Special apps | Replenish metal by salt addition |

Anode-to-cathode ratio: 1:1 to 2:1 surface area. Always use anode bags.

## Phase 6 -- Electrical Connections + Checklist + Problems

Y: 22.0" to 32.5".

**Left -- ELECTRICAL CONNECTIONS (`#E8A020`):**

```
CATHODE: Cu or Ti lead wire; soldered/bolted at non-critical area; multiple contacts for large mandrels; wire gauge for full current (< 5 V drop)
CATHODE BAR: Copper bus bar; clean contacts; bolt securely
ANODE: Separate bus bar; Ti hooks; each anode independent for balance
RECTIFIER: DC < 5% ripple; sized for max CD x area + 20%; pulse optional
```

**Right -- PRE-IMMERSION CHECKLIST (`#27AE60`):** JetBrains Mono.

```
[ ] Mandrel clean and activated
[ ] Release agent fresh (permanent)
[ ] Conductive coating intact (non-conductive -- check continuity)
[ ] Cathode lead connected securely
[ ] Conforming anodes at 100-200 mm
[ ] Shields in place at high-CD areas
[ ] Thieves connected to cathode
[ ] Anode bags installed
[ ] Anode fill sufficient for full run
[ ] Bath chemistry verified (pH, Ni, temp, stress reducer)
[ ] Filtration running (1-5 um)
[ ] Agitation set
[ ] Rectifier at STRIKE current (50-75% CD) -- NOT full CD
```

**Racking Problems (Y: 28.5" to 32.5"):** Four cards.

| Problem | Cause | Fix |
|---|---|---|
| THICK EDGES / THIN CENTER | No conforming anodes or shields | Install conforming anodes; add shields |
| NO DEPOSIT IN RECESSES | Too far from anode | Auxiliary anode inside recess; increase CD |
| CONTACT MARK DEFECT | Lead wire blocks deposition | Relocate to non-critical area; multiple contacts |
| POOR ELECTRICAL CONNECTION | Loose contact; oxide on bus bar | Clean contacts; torque bolts; measure voltage |
