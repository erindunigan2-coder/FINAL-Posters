**Inside each box (badge + name + params + purpose + check):**

- **Box 1 -- Clean:** `STAGE 1` Teal. `Nickel surface must be active` / `No separate tank -- minimal delay` / `<30 sec from Ni rinse to Cr`. Purpose: Ensure nickel is not passivated. Check: `Parts must not dry between Ni and Cr`.
- **Box 2 -- Rinse:** `STAGE 2` Teal. `Single rinse, ambient` / `Minimize dwell time`. Purpose: Remove nickel drag-out. Check: `Speed is everything -- nickel passivates in air`.
- **Box 3 -- Activation:** `STAGE 3` Amber. `Mild acid: 1--5% H2SO4 or 1--3% HCl` / `Ambient, 10--30 sec` / `Or: initial seconds in chrome bath`. Purpose: Remove nickel passive film. Check: `Many lines skip separate tank -- activate in chrome bath itself`.
- **Box 4 -- Rinse:** `STAGE 4` Teal. `Single rinse if separate activation` / `Ambient`. Purpose: Remove acid before chrome. Check: `Optional if activating in-tank`.
- **Box 5 -- Chrome Plate:** `STAGE 5` Emerald. `Cr3+: 4--8 g/L` / `pH 2.5--4.0` / `80--120 F (27--49 C)` / `50--200 ASF`. Purpose: Deposit thin, brilliant chrome over nickel. Check: `Thickness: 0.15--0.50 microns (Cr III)`.
- **Box 6 -- Rinse:** `STAGE 6` Teal. `Multi-stage, flowing` / `Ambient`. Purpose: Remove chrome drag-out. Check: `CRITICAL: Cr(VI) in drag-out is hazardous waste` (`#E05C5C`).
- **Box 7 -- Post-Treatment:** `STAGE 7` Amber. `Anti-tarnish dip (optional)` / `Hot DI water rinse` / `Ambient--160 F`. Purpose: Enhance tarnish resistance. Check: `Not always required -- depends on end-use spec`.
- **Box 8 -- Dry / Inspect:** `STAGE 8` Amber. `Forced air or oven` / `120--150 F` / `Visual + thickness check`. Purpose: Remove moisture, verify finish quality. Check: `Measure total system thickness (Cu+Ni+Cr)`.

## Phase 6 -- Hex vs. Tri Comparison

Y: 22.0" to 28.5". Section: `HEXAVALENT VS. TRIVALENT -- KNOW THE DIFFERENCE`.

**Left -- Trivalent Chrome (Cr III):**
Fill `#1E2435`, accent `#27AE60`. Title: `TRIVALENT CHROME (Cr III)` / Subtitle: `The Modern Standard`.

| Property | Value |
|---|---|
| Chemistry | Cr(III) sulfate or chloride based |
| Concentration | 4--8 g/L as Cr3+ |
| pH | 2.5--4.0 |
| Temperature | 80--120 F (27--49 C) |
| CD | 50--200 ASF |
| Cathode efficiency | 15--30% |
| Deposit color | Slightly warmer than hex |
| Thickness | 0.15--0.50 microns |
| Anodes | Graphite or MMO on titanium |
| Regulatory | RoHS/REACH compliant |

Bottom: `Automotive OEMs increasingly mandate trivalent. No carcinogenic Cr(VI) mist.` -- `#27AE60`

**Right -- Hexavalent Chrome (Cr VI):**
Fill `#1E2435`, accent `#E05C5C`. Title: `HEXAVALENT CHROME (Cr VI)` / Subtitle: `Legacy -- Still in Service`.

| Property | Value |
|---|---|
| Chemistry | CrO3 (chromic acid) + H2SO4 catalyst |
| Concentration | 200--400 g/L CrO3 |
| CrO3:SO4 ratio | 100:1 to 150:1 (CRITICAL) |
| Temperature | 95--120 F (35--49 C) |
| CD | 100--300 ASF |
| Cathode efficiency | 10--18% |
| Deposit color | Brilliant blue-white |
| Thickness | 0.25--0.75 microns |
| Anodes | Lead or lead-tin alloy (93:7) |
| Regulatory | RESTRICTED -- RoHS/REACH |

Bottom: `OSHA PEL 5 ug/m3. Known carcinogen (IARC Group 1). Enclosed ventilation required.` -- `#E05C5C`

## Phase 7 -- Troubleshooting

Y: 28.5" to 32.5". Section: `QUICK TROUBLESHOOTING -- 4 COMMON PROBLEMS`.

Four cards in a row, left accent `#E05C5C`:

| Problem | Cause | Fix |
|---|---|---|
| DULL / MILKY CHROME | CrO3:SO4 ratio off, Cr3+ too high, temp too low | Check ratio; dummy plate to reduce Cr3+ |
| CHROME PEELING | Nickel passivated before chrome immersion | Minimize Ni-to-Cr transfer time; improve activation |
| BURNING | CD too high for temperature, poor racking | Reduce CD; check temp-CD bright range |
| PITTING | Nickel pitting transferred through thin chrome | Fix nickel first; check wetting agent |
