## Phase 5 -- SSPC Standards + Profile + Defects

### SSPC Standards Matrix (Y: 14.0"-18.5")

Section label: `BLAST STANDARDS -- KNOW YOUR SPEC`. 6-row table.

| Standard | ISO | Description | Remaining | Required For |
|---|---|---|---|---|
| SP5 | Sa 3 | White Metal | 0% | IOZ (high-perf), immersion |
| SP10 | Sa 2.5 | Near-White | < 5% staining | IOZ (standard), OZ |
| SP6 | Sa 2 | Commercial | < 33% | Epoxy (new steel) |
| SP7 | Sa 1 | Brush-Off | Loose only | Sweep blast for recoat |
| SP3 | -- | Power Tool | Loose removed | Epoxy (maintenance) |
| SP11 | -- | Power Tool to Bare | Bare achieved | Spot repair |

### Profile Requirements (Y: 18.5"-20.5")

ASTM D4417: Method A (stylus), B (depth micrometer), C (replica tape -- most common field). IOZ: 1.5-3.0 mils. Epoxy: 1.5-2.5 mils. High-build: 2.0-4.0 mils.

### 6 Defects (Y: 20.5"-26.5")

Section label: `WHAT GOES WRONG -- 6 SURFACE PREP FAILURES`. 3x2 grid.

| Defect | Cause | Fix |
|---|---|---|
| FLASH RUST | Blast delay in humidity | Prime within 4 hr; dehumidify |
| ADHESION FAILURE | Residual scale or oil | Re-blast; solvent clean first |
| OSMOTIC BLISTERING | Soluble salts | Test SSPC Guide 15; water wash |
| INSUFFICIENT PROFILE | Wrong media / worn nozzle | Angular media; check nozzle |
| OVER-PROFILE | Media too aggressive | Finer grit; fill with extra primer |
| EMBEDDED CONTAMINANT | Bad media / oily air | Test media; blotter test air |
