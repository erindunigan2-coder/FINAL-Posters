## Phase 5 -- Holiday Detection + Wire vs. Arc QA Comparison

Y: 15.5" to 22.0".

**Left -- Holiday Detection Procedure (W: 11.0"):** accent `#E05C5C`.

Title: `HOLIDAY DETECTION -- SEAL COAT VERIFICATION`.

| Step | Action |
|---|---|
| 1 | Confirm seal coat fully cured |
| 2 | Wet sponge with clean tap water; damp not dripping |
| 3 | Set detector to 9-90 V DC per NACE SP0188 / ASTM D5162 |
| 4 | Attach ground clip to exposed bare metal |
| 5 | Traverse sponge at 150-300 mm/s; overlapping passes |
| 6 | Audible alarm = holiday. Mark with chalk or paint pen. |
| 7 | Repair holidays with re-applied seal coat; re-test after cure |

Acceptance: `ZERO HOLIDAYS. Any holiday means the seal coat barrier is compromised.` in JetBrains Mono `#E05C5C`.

**Right -- Wire Combustion vs. Arc Spray QA (W: 11.5"):** accent `#2EC4B6`.

Title: `WIRE COMBUSTION vs. ARC SPRAY -- QA COMPARISON`.

| Test | Wire Combustion | Arc Spray |
|---|---|---|
| Bond strength minimum | > 7 MPa | > 7 MPa |
| Thickness standard | SSPC-PA 2 | SSPC-PA 2 |
| Visual | Same criteria | Same criteria |
| Bend test | 180-degree mandrel | 180-degree mandrel |
| Holiday detection | Wet sponge; zero holidays | Wet sponge; zero holidays |
| Governing standard | AWS C2.18 | AWS C2.18 |

Wire combustion values in `#E8A020`. Arc spray values in `#2EC4B6`.

Below: `QA criteria are identical -- both processes serve the same corrosion protection function per AWS C2.18. Wire combustion runs slightly lower bond strength (7-25 vs. 10-30 MPa) but meets the same minimum.`

## Phase 6 -- Documentation + Reject Criteria

### Field Documentation Checklist (Y: 22.0"-28.5")

Section label: `FIELD QA DOCUMENTATION -- AWS C2.18`.

10-item checklist with checkbox indicators (rounded rect, border `#2EC4B6`).

| Item | Record |
|---|---|
| Surface preparation | Blast media, grit size, profile (Ra), cleanliness (SP 5/SP 10) |
| Ambient conditions | Temperature, RH, dew point, wind speed; surface temp > 3 degC above dew point |
| Blast-to-spray time | Documented with timestamp; per AWS C2.18 humidity limits |
| Wire feedstock | Material, diameter, lot number, supplier CoC |
| Spray parameters | O2/fuel/air pressures, wire feed speed, standoff |
| Coating thickness | DFT per SSPC-PA 2; spot readings by location; average and minimum |
| Seal coat application | Sealer type, lot, method, time from spray to seal, cure conditions |
| Holiday detection | Method, voltage, results (pass/fail), repairs and re-tests |
| Visual inspection | Inspector name/cert, date, time, accept/reject |
| Photographs | Before blast, after blast, during spray, after seal, final coating |

Below: `Field work demands MORE documentation, not less. Weather changes, access is limited, re-work costs are high. Record everything. Photograph everything.`

### Reject Criteria (Y: 28.5"-32.5")

Section label: `REJECT CONDITIONS -- STRIP AND RE-SPRAY`. Four cards, left accent `#E05C5C`.

| Condition | Action |
|---|---|
| THICKNESS BELOW MINIMUM | Add spray if bond sound. If sealed, strip seal first -- no re-spray over seal. |
| BOND STRENGTH BELOW 7 MPa | Strip by blast; investigate prep quality; re-blast and re-spray. |
| PERSISTENT HOLIDAYS | Re-seal and re-test. If persistent, strip seal, investigate porosity, re-seal correctly. |
| BARE SPOTS OR DELAMINATION | Strip affected area by blast; re-spray. Common causes: contamination, insufficient profile, moisture. |
