## Phase 5 -- Transfer Speed + Load Configuration

**15-Second Rule** (Coral accent): Same as austempering. Methods: robot 3--6 sec, conveyor 5--8, crane 8--12, manual 10--20 (RISKY). Warning: manual regularly exceeds 15 sec.

**Load Configuration for Equalization** (3 columns): Dense load (Coral): parts packed, center equalizes slowly, non-uniform martensite. Properly spaced (Emerald): 0.25" salt / 0.5" oil, all parts equalize equally. Equalization times: 0.5" = 3--5 min, 1.0" = 5--8, 1.5" = 8--12, 2.0" = 12--15 (preheat above 2").
