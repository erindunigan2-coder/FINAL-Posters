## Phase 6 -- Sealer + Dry/Cure

Y: 22.0" to 27.0". Section: `SEALER & DRY/CURE -- THE FINAL STEPS`.

**Left -- Sealer (X: 0.5", W: 11.0"):**
Title: `TOPCOAT SEALER (OPTIONAL)` `#2EC4B6`.
- Organic or silicate-based
- 150--180 F, 30--60 sec
- Fills micro-pores, 2--3x salt spray boost
- Changes friction coefficient -- check torque specs

**Right -- Dry/Cure (X: 12.0", W: 11.5"):**
Title: `DRY / CURE` `#E8A020`.
- Forced air/oven/IR, 150--170 F, 15--20 min
- Under-cure = soft film = poor performance
- Over-cure (> 200 F / 93 C) = degradation
- H-bake for HTS: 375 F x 23 hr BEFORE passivation

Bottom note: `High-strength steel >= 145 ksi / >= 31 HRC: bake at 375 F BEFORE passivation -- per ASTM B850` `#E05C5C`.

## Phase 7 -- Problems + Safety

Y: 27.0" to 32.5".

**Left -- Problems (X: 0.5", W: 14.0"):**

| Problem | Cause | Fix |
|---|---|---|
| No passivate color | pH too high (drag-in) | Improve rinse; check pH |
| Patchy color | Contaminated bath | Dump/remake; improve rinse |
| Peeling passivate | Over-immersion | Reduce time |
| Poor salt spray | Under-cure / no sealer | Sealer + full cure |
| Iridescent shift | Cr3+ depletion | Replenish per TDS |
| Blistering after bake | H-bake after passivate | Bake BEFORE passivation |

**Right -- Safety (X: 15.0", W: 8.5"):**
Title: `SAFETY -- POST-TREATMENT` `#E8A020`.
- Acidic baths (pH 1.5--4.5): burns
- Hex Cr6+: CARCINOGENIC -- full PPE + ventilation + medical surveillance
- Tri: lower hazard, still acidic
- Sealer: hot (150--180 F), thermal burns
- Cr6+ waste: REGULATED, special treatment
- All Cr6+ ops require medical monitoring
