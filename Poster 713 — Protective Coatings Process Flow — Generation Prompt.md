|---|---|---|---|

## Phase 5 -- System Architecture + Service Environments

### System Architecture (Y: 15.5"-22.0")

Section label: `THREE-COAT SYSTEM ARCHITECTURE`. Cross-section stack on steel substrate.

Layer 1 -- Primer: Zinc-rich or epoxy, 2-4 mils `#27AE60`. Corrosion/galvanic.
Layer 2 -- Intermediate: High-build epoxy, 4-8 mils `#2EC4B6`. Barrier + chemical resistance.
Layer 3 -- Topcoat: Aliphatic polyurethane, 2-3 mils `#E8A020`. UV, color, gloss.
Total bracket: `6-20+ mils`.

2K callout: `Why two-component? Epoxy and urethane cross-link into thermosets. Chemistry requires mixing immediately before application.`

### Service Environments (Y: 22.0"-28.5")

Section label: `WHERE THESE SYSTEMS ARE SPECIFIED`. 3x2 grid of cards.

| Environment | System | DFT |
|---|---|---|
| Marine / Offshore | IOZ + epoxy + PU | 10-16 mils |
| Tank Lining | Solventless epoxy (NSF 61) | 12-20+ mils |
| Concrete Floors | Epoxy primer + epoxy topcoat | 10-15 mils |
| Pipeline (External) | FBE or liquid epoxy | 12-25 mils |
| Bridge / Infrastructure | IOZ + epoxy + PU (ISO 12944) | 10-14 mils |
| Chemical Processing | Novolac epoxy | 15-25 mils |

## Phase 6 -- Troubleshooting

Y: 28.5" to 32.5". Four cards, left accent `#E05C5C`.

| Problem | Cause | Fix |
|---|---|---|
| INTERCOAT DELAMINATION | Amine blush; exceeded recoat | Wash blush; scuff sand if window exceeded |
| SOLVENT ENTRAPMENT | Applied too thick | Reduce DFT per coat; adequate flash |
| HOLIDAYS (PINHOLES) | Thin at edges/welds | Stripe coat edges; holiday test entire surface |
| PREMATURE TOPCOAT FAILURE | Aromatic urethane for exterior | Specify ALIPHATIC PU for UV exposure |
