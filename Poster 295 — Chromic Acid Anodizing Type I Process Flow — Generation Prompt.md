## Phase 5 -- Parameter Summary Table

Y: 15.5" to 22.0". Section: `AT-A-GLANCE PARAMETERS`.

| Stage | Chemistry | Temp | Time | Key Control |
|---|---|---|---|---|
| 1. Alkaline Clean | Non-silicated, Cl-free cleaner | 130--160 F | 2--10 min | Water-break-free |
| 2. Rinse | DI cascade | Ambient | 30--60 sec | <200 uS/cm |
| 3. Etch | Light NaOH 20--40 g/L or NONE | 130--150 F | 0--2 min | Spec-dependent; often prohibited |
| 4. Desmut | HNO3 25--50%; HF for Cu alloys | Ambient | 30--120 sec | Complete smut removal |
| 5. Rinse (Pre-Anodize) | DI triple cascade | Ambient | 60--120 sec | <50 uS/cm; Cl-/F- free |
| 6. Anodize | CrO3 30--50 g/L | 90--100 F | 30--60 min | VOLTAGE RAMP: 0->20->40 V |
| 7. Rinse (Post-Anodize) | DI water | Ambient | 30--60 sec | Remove residual Cr(VI) |
| 8. Seal | Hot DI or Ni acetate or UNSEALED | 158--212 F | 15--30 min | Often left unsealed for paint base |

## Phase 6 -- Type I vs BSAA Comparison

Y: 22.0" to 28.5". Section: `THE REGULATORY TRANSITION -- TYPE I VS. BSAA`.

**Left -- Type I (This Poster):**
Accent `#E8A020`. Title: `TYPE I -- CHROMIC ACID`. Subtitle: `The Aerospace Legacy`.

| Property | Value |
|---|---|
| Electrolyte | CrO3 30--50 g/L (Cr6+) |
| Film thickness | 0.5--2.5 um |
| Fatigue effect | NONE (<5% reduction) |
| Self-healing | YES (Cr6+ reservoir) |
| Corrosion (B117) | 168--336 hrs (sealed) |
| Environmental | Cr6+ -- CARCINOGENIC |
| RoHS/REACH | RESTRICTED |
| MIL spec | MIL-A-8625F Type I/IB |

Highlight bar: `Technically elegant but environmentally unacceptable. The industry is moving away.` `#E05C5C`

**Right -- BSAA (Replacement):**
Accent `#27AE60`. Title: `BSAA -- BORIC-SULFURIC ACID`. Subtitle: `The Cr(VI)-Free Future`.

| Property | Value |
|---|---|
| Electrolyte | H2SO4 + H3BO3 (no Cr6+) |
| Film thickness | 2--8 um |
| Fatigue effect | MINIMAL (<10% reduction) |
| Self-healing | NO (no Cr6+ reservoir) |
| Corrosion (B117) | 168--336 hrs (sealed) |
| Environmental | Cr6+-FREE |
| RoHS/REACH | COMPLIANT |
| MIL spec | MIL-A-8625F Type IC |

Highlight bar: `Equivalent corrosion protection without hexavalent chromium. Approved by Boeing, Airbus, Lockheed.` `#27AE60`

## Phase 7 -- Troubleshooting

Y: 28.5" to 32.5". Section: `QUICK TROUBLESHOOTING -- 4 COMMON PROBLEMS`.

| # | Problem | Cause | Fix |
|---|---|---|---|
| 1 | IRIDESCENT/THIN COATING | CrO3 too low; voltage too low; time too short | Analyze CrO3; verify voltage ramp profile |
| 2 | BLISTERING | Sulfate contamination >0.5 g/L in bath | Analyze bath for SO4; precipitate with Ba |
| 3 | POOR ADHESION | Cleaner residue; smut under coating | Improve cleaning; verify desmut |
| 4 | UNEVEN COLOR | Voltage ramp deviation; poor agitation | Calibrate rectifier; improve air agitation |
