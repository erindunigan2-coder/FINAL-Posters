### ZONE 4 -- Sulfamate vs. Watts Comparison

**Section label:**

> SULFAMATE VS. WATTS -- CHOOSING YOUR NICKEL BATH

**BLOCK E -- Side-by-Side Comparison**

**Left -- Sulfamate Nickel:**
- Rounded rect, fill `#1E2435`, left accent `#E8A020`
- Title: `SULFAMATE NICKEL` Barlow SemiBold 20 pt `#E8A020`
- Subtitle: `The Engineering Standard`

| Property | Value |
|---|---|
| Primary salt | Ni(SO3NH2)2 + H3BO3 |
| Temperature | 130--145 F (54--63 C) |
| Current density | 20--75 ASF; up to 200+ ASF with agitation |
| Cathode efficiency | 96--100% |
| Deposit type | Matte (no brighteners typically) |
| Internal stress | Near-zero to compressive (controllable) |
| Typical use | Electroforming, aerospace, buildup/salvage |
| Brighteners | Rarely -- stress control is priority |
| Chloride | Optional (0--30 g/L); can run chloride-free |
| Cost | Higher (sulfamate salt premium) |

Bottom highlight: `The only nickel process that can achieve near-zero internal stress. The standard for electroforming, waveguides, molds, and fatigue-critical components.`

**Right -- Watts Nickel:**
- Rounded rect, fill `#1E2435`, left accent `#27AE60`
- Title: `WATTS NICKEL` Barlow SemiBold 20 pt `#27AE60`
- Subtitle: `The Decorative & Functional Standard`

| Property | Value |
|---|---|
| Primary salt | NiSO4 + NiCl2 + H3BO3 |
| Temperature | 130--150 F (54--66 C) |
| Current density | 30--50 ASF (rack) |
| Cathode efficiency | 92--98% |
| Deposit type | Semi-bright to bright (with additives) |
| Internal stress | Tensile (moderate) |
| Typical use | Decorative, undercoat for chrome, functional |
| Brighteners | Yes -- Class I + Class II system |
| Chloride | Required (37--55 g/L NiCl2) |
| Cost | Lower operating cost |

Bottom highlight: `Most versatile nickel process -- bright appearance, good leveling, broad application range. The workhorse of decorative plating.`

### ZONE 5 -- Troubleshooting Quick Hits

**Section label:**

> QUICK TROUBLESHOOTING -- 4 COMMON SULFAMATE NICKEL PROBLEMS

**BLOCK F -- Four Problem Cards**

| Card | Problem | Cause | Fix |
|---|---|---|---|
| 1 | HIGH TENSILE STRESS | Organic contamination, sulfamate hydrolysis, excess chloride | Carbon treat; check bath temp (>160 F hydrolyzes); reduce chloride |
| 2 | BRITTLE DEPOSIT | Excessive saccharin, metallic contamination | Reduce saccharin; dummy plate |
| 3 | PITTING | Low wetting agent, particulates, poor agitation | Add anti-pit; improve filtration; increase agitation |
| 4 | ROUGH DEPOSIT | Anode sludge, particulate, insufficient filtration | Inspect anode bags; increase filtration turnover |

Cards: fill `#1E2435`, left accent `#E05C5C`.

## Design Notes

This poster mirrors Poster #55 structurally but the content DNA is different. Sulfamate nickel is an engineering process, not a decorative one. The tagline, parameters, and troubleshooting all reflect this. The sulfamate vs. Watts comparison is the inverse of Poster #55's comparison -- now sulfamate is on the left (hero position). The key differentiator to hammer home: sulfamate = low stress, Watts = appearance. If you need the deposit to survive mechanical loading, bending, or fatigue, sulfamate is the only answer.
