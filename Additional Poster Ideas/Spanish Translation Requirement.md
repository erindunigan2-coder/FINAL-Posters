# Spanish Translation Requirement — Standing Requirement

## Requirement

**All Plating Posters Inc posters — current and future — will be produced in Mexican Spanish (es-MX) editions in addition to English.**

This applies to:
- Series 1 (Posters #1–#30) — all existing English posters need es-MX versions
- Series 2–10 (Posters #31–#720) — all new granular posters need es-MX versions concurrently or after English

**Total scope:** ~720 English + ~720 Mexican Spanish = **~1,440 poster designs**

---

## Language Specification

- **Dialect:** Mexican Spanish (es-MX) — NOT Castilian (es-ES)
- **Tone:** Shop floor appropriate — clear, direct, professional. Accessible to operators and technicians.
- **Technical terms:** Use standard industry terminology in Spanish where established (e.g., "densidad de corriente," "cátodo," "ánodo," "chapado"). Do not translate proprietary product names.
- **Units:** Same dual units as English (g/L and oz/gal; ASF; °F and °C)
- **Chemical formulas/symbols:** Unchanged — these are universal

---

## Workflow

Spanish editions are produced AFTER the English version of each poster is complete and approved.

## File Naming Convention (Spanish Editions)

Append `— es-MX` to all Spanish edition file names:

| English File | Spanish File |
|---|---|
| `[Title] — Dark — 24x36 — Print.pdf` | `[Title] — es-MX — Dark — 24x36 — Print.pdf` |
| `[Title] — Dark — 18x24 — Print.pdf` | `[Title] — es-MX — Dark — 18x24 — Print.pdf` |
| `[Title] — Dark — Digital.pdf` | `[Title] — es-MX — Dark — Digital.pdf` |
| `[Title] — Light — 24x36 — Print.pdf` | `[Title] — es-MX — Light — 24x36 — Print.pdf` |
| `[Title] — Light — 18x24 — Print.pdf` | `[Title] — es-MX — Light — 18x24 — Print.pdf` |
| `[Title] — Light — Digital.pdf` | `[Title] — es-MX — Light — Digital.pdf` |

Six English files + six Spanish files = **12 files per poster total.**

## Notes

- Same color palette, typography, and layout as English editions — only text content changes
- Series name in footer: `Plating Posters Inc — Serie de Referencia para Acabados Metálicos`
- Disclaimer in footer must be translated to es-MX
- Poster titles/headlines translated; chemical formulas, hex codes, and numeric values unchanged
- Do NOT use machine translation alone — content must be reviewed for technical accuracy in context
