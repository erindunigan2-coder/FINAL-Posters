# Poster Accuracy and Neutrality Standards — NON-NEGOTIABLE

## Two Absolute Rules

### Rule 1 — Zero Supplier, Brand, or Product References

Every poster in the Plating Posters Inc series must be **100% generic and universal.** No exceptions.

**Never include:**
- Supplier names (e.g., Enthone, MacDermid, Atotech, Chemours, Stepan, Aldoa, A Brite, or any other)
- Brand/trade names (e.g., Triton, Iridite, Alodine, Bonderite, or any proprietary product name)
- Distributor names
- Any reference that implies a specific commercial product

**Why:** These are educational reference products sold to any shop running any chemistry from any supplier. Product placement would compromise the educational credibility and universal applicability of the series. A shop running Supplier A's chemistry and a shop running Supplier B's chemistry must both find the poster equally accurate and useful.

**How to handle supplier-sourced data:**
- Reference only the underlying chemistry/standard (e.g., "trivalent chromate passivate" — NOT any brand name)
- Use only ASTM, ISO, MIL-SPEC, or general industry consensus values
- If a process parameter varies by supplier formulation, state the typical industry range and note "consult your process supplier TDS for product-specific values"
- Footer disclaimer must always include: "Operating parameters and chemistry values are typical industry ranges. Consult your process chemistry supplier for product-specific formulations and operating windows."

### Rule 2 — Technical Accuracy is Non-Negotiable

All operating parameters, chemistry values, process sequences, and technical claims must be correct.

**Standards for accuracy:**
- Use only established industry consensus values (NASF publications, AES/NASF Plating and Surface Finishing journal, ASTM standards, MIL specifications, Nickel Institute, Chromate Institute, etc.)
- When a range exists, show the range — do not pick a single value arbitrarily
- When a value is process-dependent or substrate-dependent, say so
- Do not invent values or extrapolate beyond established data
- Flag any value that is uncertain with a Watson/Tyler review note in the Construction Workup

**If uncertain about a value:**
- Flag it in the Construction Workup with: `⚠️ VERIFY: [specific claim] — Watson/Tyler review needed before generation`
- Do not guess or approximate — an inaccurate poster is worse than an incomplete one
- Watson is the research resource for uncertain technical content
- Tyler is the validation resource for lab-verified process details

---

## Disclaimer Language (Required on Every Poster)

The footer of every poster must include this disclaimer (or equivalent):

> *This poster is an educational reference tool. Operating parameters, chemistry values, and process sequences represent typical industry ranges and general best practice. Specific values vary by substrate, geometry, bath formulation, and operating conditions. Always consult your process chemistry supplier's technical data sheet and applicable industry standards for application-specific guidance.*

Adjust wording slightly per poster topic as needed — but the substance must always be present.

---

## What IS Acceptable

- Generic chemical names: "zinc sulfate," "sodium hydroxide," "trivalent chromium passivate," "hydrochloric acid"
- Chemical formulas: ZnSO₄, NaOH, HCl, H₂SO₄, Cr³⁺
- Industry standard test methods: ASTM B117, ASTM B499, MIL-QQ-Z-325
- Process types by chemistry class: "acid chloride zinc," "alkaline non-cyanide zinc," "high-phosphorus electroless nickel"
- Established parameter ranges from authoritative industry sources
