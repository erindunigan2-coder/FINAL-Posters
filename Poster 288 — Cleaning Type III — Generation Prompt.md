## Phase 5 -- Contamination Amplification + Water Break Test

Y: 14.5" to 20.5".

**Left -- Contamination Amplification:**

| Contamination | Effect on Type II (12--18 ASF) | Effect on Type III (24--36 ASF) |
|---|---|---|
| Fingerprint | Faint shadow | White burn mark -- coating dissolved |
| Oil film | Thin spot, cosmetic | Bare spot with aggressive burning |
| Silicate deposit | Skip anodizing | No oxide growth; adjacent area over-anodizes and burns |
| Embedded particle | Minor inclusion | Delamination under thick, stressed coating |

Below: `High current density concentrates at any discontinuity. What Type II tolerates, Type III punishes.` `#E8A020`

**Right -- Water Break Test:**
PASS (`#27AE60`): Continuous water film. FAIL (`#E05C5C`): Water beads or breaks.

## Phase 6 -- Defect Diagnosis Grid

Y: 20.5" to 26.5". Section: `WHAT GOES WRONG -- 6 CLEANING FAILURES`.

3x2 grid:
| Defect | Cause | Fix |
|---|---|---|
| BURNING AT DEFECT SITES | Organic residue concentrates current | Re-clean; ultrasonic for critical parts |
| SKIP ANODIZING | Silicate deposit | Replace cleaner with non-silicated |
| DELAMINATION | Embedded particles under thick oxide | Solvent pre-clean; ultrasonic |
| POWDERY COATING (localized) | Partial oil film causes local overheating | Extend soak time; increase temp |
| STREAKING | Inadequate rinsing after clean | Improve cascade rinse |
| NON-UNIFORM COLOR | Uneven soil removal | Improve agitation; verify concentration |

## Phase 7 -- Ultrasonic + Hardcoat-Specific Rules

Y: 26.5" to 32.5".

**Left -- Type III Cleaning Rules:**
1. Same non-etch alkaline cleaner as Type II
2. Extend soak for heavily soiled parts
3. Solvent pre-clean for buffing compounds
4. Ultrasonic for precision aerospace/hydraulic parts
5. Water-break test is MANDATORY
6. Any drag-over dilutes the low-concentration anodize bath

**Right -- Ultrasonic Cleaning:**
`WHEN TO ADD ULTRASONIC`: Blind holes/recesses, embedded buffing compound, aerospace parts per AMS 2469, any part failing water-break test. Parameters: `25--40 kHz, 130--150 F, 3--10 min`. Use AFTER alkaline soak, not as replacement.
