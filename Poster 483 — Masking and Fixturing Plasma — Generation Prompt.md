## Phase 4 -- Masking Materials + Fixturing Rules (HERO)

Y: 4.2" to 14.5". Section label: `MASKING MATERIALS FOR APS`.

**Masking Materials Table (left, W: 13.0"):**

| Material | Temp Rating | Reusable? | Best For | Limitations |
|---|---|---|---|---|
| Hi-temp silicone tape | 260 degC (500 degF) | No | Quick masking of flat surfaces, edges | Adhesive residue; single use |
| Metal masks (steel, SS, Cu) | > 500 degC | Yes | Production runs; repeatable geometry | Requires machining; cost |
| Silicone plugs & caps | 260 degC (500 degF) | Yes (limited) | Holes, bores, threaded features | Must fit snugly; heat deformation |
| Ceramic fiber tape | > 1000 degC | No | Extreme temp zones near plume | Fragile; limited adhesion |
| Liquid maskant (peelable) | 200-300 degC | No | Complex shapes; spray-applied | Curing time; thickness control |

**Fixturing Design Rules (right, W: 9.5"):** Six numbered rule cards, left accent `#2EC4B6`:

| Rule | Text |
|---|---|
| 1 | Rotation: 60-200 RPM for cylindrical parts |
| 2 | Uniform standoff -- fixture must hold part rigidly |
| 3 | Cooling air nozzles at substrate backside |
| 4 | No fixture shadow on spray pattern |
| 5 | Ground fixture to workpiece (prevent ESD) |
| 6 | Sacrificial test tabs on same fixture |

## Phase 5 -- Temperature Exposure + Common Mistakes

### Temperature Exposure (Y: 14.5"-20.5")

Section label: `MASKING MUST SURVIVE THE HEAT`. Horizontal temp bar:

| Zone | Range | Color |
|---|---|---|
| Standard tape | 0-200 degC | `#27AE60` at 30% |
| Silicone/liquid maskant | 200-300 degC | `#E8A020` at 30% |
| Metal mask required | 300-500 degC | `#E05C5C` at 30% |
| Ceramic fiber or bare | 500+ degC | `#E05C5C` at 50% |

Markers: APS substrate 80-200 degC typical. Direct plume >1000 degC. Note: `Position masks so they are never in the direct spray path.` `#E8A020`.

### Common Mistakes (Y: 20.5"-26.5")

Section label: `4 MASKING & FIXTURING MISTAKES`. Four coral-accented cards:

| Problem | Cause | Fix |
|---|---|---|
| COATING UNDER MASK | Mask not sealed; gap at edge | Press firmly; metal masks for tight tolerance |
| FIXTURE SHADOW | Fixture blocks spray path | Redesign for full line-of-sight |
| THERMAL DISTORTION | Part overheats; warps on fixture | Add cooling air; reduce pass dwell time |
| ADHESIVE RESIDUE | Tape residue contaminates surface | Silicone-adhesive tapes; remove before post-treatment |

## Phase 6 -- Pre-Spray Checklist

Y: 26.5" to 32.5". Section label: `PRE-SPRAY FIXTURE VERIFICATION`. Two columns, 5 items each with checkboxes:

| Item |
|---|
| Part securely fixtured -- no wobble |
| Masking complete and inspected |
| No tape in direct spray path |
| Cooling air positioned and tested |
| Fixture does not shadow coated area |
| Sacrificial test tabs installed |
| Rotation speed set and verified |
| Part grounded to fixture |
| All non-coated features masked |
| Standoff distance verified at all positions |
