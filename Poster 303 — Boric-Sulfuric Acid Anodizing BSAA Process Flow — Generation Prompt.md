## Phase 5 -- Parameter Summary Table

Y: 15.5" to 22.0". Section: `AT-A-GLANCE PARAMETERS`.

| Stage | Chemistry | Temp | Time | Key Control |
|---|---|---|---|---|
| 1. Alkaline Clean | Non-silicated, Cl-free cleaner | 130--160 F | 2--10 min | Water-break-free |
| 2. Rinse | DI cascade | Ambient | 30--60 sec | <200 uS/cm |
| 3. Etch | Light NaOH or NONE | 130--150 F | 0--2 min | Often skipped for BSAA |
| 4. Desmut | HNO3 25--50%; HF for Cu alloys | Ambient | 30--120 sec | Complete smut removal |
| 5. Rinse (Pre-Anodize) | DI triple cascade | Ambient | 60--120 sec | <50 uS/cm; Cl-/F- free |
| 6. BSAA Anodize | H2SO4 30--50 g/L + H3BO3 5--10 g/L | 80--90 F | 15--25 min | VOLTAGE RAMP to ~15 V |
| 7. Rinse (Post-Anodize) | DI water | Ambient | 30--60 sec | Standard |
| 8. Seal | Hot DI or Ni acetate (NO dichromate) | 158--212 F | 15--30 min | Cr(VI)-free seal only |

## Phase 6 -- BSAA vs Type I Comparison

Y: 22.0" to 28.5". Section: `THE REPLACEMENT -- BSAA VS. TYPE I`.

**Left -- BSAA (This Poster):**
Accent `#27AE60`. Title: `BSAA -- TYPE IC`. Subtitle: `The Cr(VI)-Free Future`.

| Property | Value |
|---|---|
| Electrolyte | H2SO4 + H3BO3 (no Cr6+) |
| Film thickness | 2--8 um |
| Fatigue effect | MINIMAL (<10% reduction) |
| Self-healing | NO |
| Corrosion (B117, sealed) | 168--336 hrs |
| Environmental | Cr6+-FREE |
| RoHS/REACH | COMPLIANT |
| Spec | MIL-A-8625F Type IC; BAC 5632 |

Highlight bar: `Equivalent corrosion protection without hexavalent chromium. Approved by Boeing, Airbus, Lockheed.` `#27AE60`

**Right -- Type I (Legacy):**
Accent `#E05C5C`. Title: `TYPE I -- CHROMIC ACID`. Subtitle: `The Aerospace Legacy`.

| Property | Value |
|---|---|
| Electrolyte | CrO3 30--50 g/L (Cr6+) |
| Film thickness | 0.5--2.5 um |
| Fatigue effect | NONE (<5%) |
| Self-healing | YES (Cr6+ reservoir) |
| Corrosion (B117, sealed) | 168--336 hrs |
| Environmental | Cr6+ -- CARCINOGENIC |
| RoHS/REACH | RESTRICTED |
| Spec | MIL-A-8625F Type I/IB |

Highlight bar: `Technically elegant but being phased out. Self-healing is the only property BSAA cannot replicate.` `#E05C5C`

## Phase 7 -- Troubleshooting

Y: 28.5" to 32.5". Section: `QUICK TROUBLESHOOTING -- 4 COMMON PROBLEMS`.

| # | Problem | Cause | Fix |
|---|---|---|---|
| 1 | THIN/IRIDESCENT COATING | Voltage too low; time too short; boric acid depleted | Verify voltage ramp; check boric acid concentration |
| 2 | POWDERING | Temperature too high or acid too concentrated | Cool bath; check H2SO4 concentration |
| 3 | PITTING | Chloride contamination in bath | Analyze for Cl-; improve pre-anodize rinse |
| 4 | POOR PAINT ADHESION | Over-sealed (too long or too hot) | Reduce seal time; verify spec requirement |
