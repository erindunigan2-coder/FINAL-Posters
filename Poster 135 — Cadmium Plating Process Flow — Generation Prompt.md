**Top Row:** 1. Soak Clean / Electroclean (`#2EC4B6`) | 2. Rinse Pre-Act (`#2EC4B6`) | 3. Acid Activation (`#E8A020`) | 4. Rinse Pre-Plate (`#2EC4B6`).
**Bottom Row:** 5. Cadmium Plate (`#27AE60`) | 6. Rinse Post-Plate (`#2EC4B6`) | 7. Chromate Conversion (`#E8A020`) | 8. HE Bake (`#E05C5C`, **double border 3pt**).

Box 1: `Vapor degrease or soak clean` / `Electroclean anodic 3--5 min` / `Minimize H2 exposure`. Check: `Short electroclean -- minimize hydrogen`.
Box 2: `Ambient` / `Flowing`. Check: `Standard`.
Box 3: `HCl 10--20%` / `Ambient, 15--30 sec MAX`. Check (Coral): `MINIMIZE TIME -- H-embrittlement risk on high-strength steel`.
Box 4: `Ambient` / `Flowing`. Check (Coral): `SAFETY: Acid to cyanide = HCN gas`.
Box 5: `Cd: 18--35 g/L` / `NaCN: 90--150 g/L` / `75--90 F` / `10--25 ASF`. Check: `Free NaCN: 15--45 g/L`.
Box 6: `Double counterflow` / `Cd waste segregation`. Check (Coral): `Cd rinse water is hazardous waste`.
Box 7: `Type I (Clear): 48--96 hr WSS` / `Type II (Gold): 96--200 hr` / `Type III (OD): 200--400 hr`. Check: `Almost always hexavalent chromate`.
Box 8 (LIFE-SAFETY, double border Coral): `375 +/- 25 F` / `12--24 hr (per AMS 2759/9)` / `WITHIN 1 HOUR OF PLATING`. Check (Coral): `NOT OPTIONAL. Delayed bake has caused fatal aircraft failures.`
