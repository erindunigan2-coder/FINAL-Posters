## Phase 5 -- Parameter Table + Compound Zone Growth

### Parameter Table (Y: 15.5"--22.0")

Section label: `CYCLE CONTROL PARAMETERS -- COMPLETE REFERENCE`.

8-row table:

| Parameter | Value | Control Method | Frequency |
|---|---|---|---|
| FNC bath temperature | 1050--1125 F; target 1075 F | Thermocouple + controller | Continuous |
| FNC immersion time | 60--120 min standard; up to 240 | Timer | Per load |
| Cyanate content (CNO) | 35--40% | Titration | Every shift |
| Cyanide content (CN) | Below regulatory limit | Analysis | Per schedule |
| Oxidizing bath temp | 700--800 F | Thermocouple + controller | Continuous |
| Oxidizing immersion | 15--30 min (Q1 and Q2 each) | Timer | Per load |
| Polish finish | Ra 8--16 micro-inch | Profilometer | Per lot |
| Bath sludge | Minimal | Visual + ladle | Weekly |

Header `#3A4055`. ASTM/spec references in `#E8A020`.

### Compound Zone Growth (Y: 22.0"--28.5")

Section label: `COMPOUND ZONE THICKNESS VS. IMMERSION TIME`.

**Left -- Growth Table (Emerald):** At 1075 F: 60 min = 10--15 um | 90 min = 13--20 um | 120 min = 15--25 um | 240 min = 25--38 um. Note: parabolic growth -- doubling time does NOT double thickness.

**Right -- Factors Affecting Zone (Amber):** Temperature (higher = faster, stay below Ac1), Time (diminishing returns past 120 min), Bath composition (higher CNO = faster), Substrate (alloy steels respond differently -- stainless slower), Surface condition (clean/oxide-free absorbs faster).

## Phase 6 -- Cycle Time Comparison

Y: 28.5" to 32.5". Section label: `CYCLE TIME COMPARISON`.

Four cards, left accent `#2EC4B6`:

| Process | Cycle Time |
|---|---|
| FNC/Q-P-Q (SALT BATH) | 2.5--5 hr total. Wear + corrosion in one cycle. |
| GAS NITRIDING | 24--90 hr. Deeper case but dramatically longer. No built-in corrosion. |
| HARD CHROME PLATE | 2--8 hr plating. But hexavalent chromium. Q-P-Q is the replacement. |
| GAS FNC (ATMOSPHERE) | 2--4 hr FNC step only. No oxidizing quench = lower corrosion. |
