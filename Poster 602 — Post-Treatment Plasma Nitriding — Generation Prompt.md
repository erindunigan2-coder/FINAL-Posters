## Phase 4 -- Decision Tree (HERO)

Y: 2.9" to 15.5". Section label: `POST-TREATMENT DECISION TREE`.

Flow from `PARTS UNLOADED FROM CHAMBER`:
- Decision 1: COMPOUND LAYER PRESENT?
  - YES -> Decision 2: SPEC REQUIRES REMOVAL?
    - YES -> LAP/GRIND WHITE LAYER (0.0002--0.001 in removal) -> INSPECT -> SHIP
    - NO -> Decision 3: OXIDATION/COATING DESIRED?
      - YES -> CONTROLLED OXIDATION or COATING (steam oxidation, oil quench, PVD)
      - NO -> INSPECT -> SHIP (compound layer retained)
  - NO -> NO COMPOUND LAYER (process run at < 10% N2) -> INSPECT -> SHIP

Boxes fill `#1E2435`. Decision diamonds border `#E8A020`. Arrows 3 pt `#3A4055`.

## Phase 5 -- Compound Layer Management

Y: 15.5" to 22.0". Section label: `COMPOUND LAYER -- KEEP, REMOVE, OR PREVENT`. 3 columns:

**KEEP (`#27AE60`):** Wear applications; corrosion barrier; general industrial. No post-treatment; inspect directly.

**REMOVE (`#E05C5C`):** Fatigue-critical; some aerospace specs. Precision lapping < 0.001 in; fine grinding; avoid damaging diffusion zone.

**PREVENT (`#2EC4B6`):** Maximum fatigue life; process run at < 10% N2 / > 90% H2. Controlled during cycle, not post-treatment. UNIQUE TO PLASMA.
