## Phase 4 -- Hardness Testing Methods (HERO)

Y: 2.9" to 12.5". Section label: `HARDNESS TESTING -- METHOD SELECTION`. 3 tall cards:

**SUPERFICIAL ROCKWELL (`#27AE60`, PRODUCTION):** HR15N/30N/45N; light loads stay in case; for screening/pass-fail; not for case < 0.005 in; Nitralloy spec: 92+ HR15N.

**MICROHARDNESS TRAVERSE (`#E8A020`, DEFINITIVE):** Vickers/Knoop 100--500 gf; step from surface inward at 0.001--0.002 in; plot HV vs. depth; ECD = depth to core + 50 HV or 513 HV. Gold standard.

**STANDARD ROCKWELL HRC (`#E05C5C`, OFTEN INAPPROPRIATE):** 150 kgf penetrates 0.003--0.005 in; reads THROUGH thin case into soft core; falsely low. NEVER use for spec compliance on standard nitriding. Caution: `Using HRC on 0.010 in case gives FALSE LOW reading.`

## Phase 5 -- White Layer + Case Depth

### White Layer (Y: 12.5"--19.0")

Section label: `WHITE LAYER (COMPOUND ZONE) -- MEASUREMENT & CLASSIFICATION`.

**Left -- HOW TO MEASURE:** Section, mount, polish, examine unetched/light nital 400--1000x; WL appears bright against dark diffusion zone. Single-stage 0.0005--0.001 in; two-stage 0--0.0005 in; Class 0 (KN) = ZERO.

**Right -- EPSILON vs. GAMMA-PRIME:** Epsilon (Fe2-3N): 800--1200 HV, harder, more brittle, spalling risk. Gamma-prime (Fe4N): 600--800 HV, tougher, more ductile, fatigue-friendly. Identified by XRD/GDOES. Ratio controlled by KN and temperature.

### Case Depth (Y: 19.0"--25.5")

Section label: `CASE DEPTH -- DEFINITION & MEASUREMENT`.

**Left -- ECD Definition:** Def 1 (SAE J423): depth to 50 HRC (~513 HV). Def 2: depth to core + 50 HV. Example: core 350 HV, ECD = depth to 400 HV. Typical 0.005--0.030 in.

**Right -- Methods:** (1) Microhardness traverse (primary); (2) Nitrogen profile (GDOES/EPMA, research); (3) File test (shop floor, qualitative, NOT for spec); (4) Fracture test (qualitative).

## Phase 6 -- Defect Identification

Y: 25.5"--32.5". Section label: `COMMON DEFECTS -- IDENTIFICATION, CAUSE & REMEDY` in `#E05C5C`. 6-row table:

| Defect | Detection | Cause | Remedy |
|---|---|---|---|
| Excessive white layer | Metallography | KN too high; single-stage; too long | 2-stage; reduce KN |
| No white layer (when req'd) | Metallography | KN too low; poor atmosphere | Increase KN; check NH3/leaks |
| Spalling/flaking | Visual | Thick brittle epsilon | Control to gamma-prime; reduce WL |
| Soft spots | Superficial Rockwell | Contamination; Cr passive film; contact | Clean; activate; fix fixturing |
| Core softening | Core hardness below spec | Nitride temp > temper temp | Verify temper > nitride + 50 F |
| Uneven case | Traverse varies | Poor circulation; parts too close | Fix fixturing; increase fan; reduce load |
