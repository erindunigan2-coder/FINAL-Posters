## Phase 5 -- Chrome Seal Dilemma

Y: 14.5" to 20.5". Section: `THE CHROME SEAL DILEMMA`.

**Left -- Chrome Seal (MIL-DTL-16232 Class 2):** Coral accent. Badge: `REQUIRED BY MIL-SPEC`. Cr(VI) passivates micropores. Class 2 DEFINITION. OSHA PEL 5 ug/m3. Bottom: `Military shops running Class 2 MUST use chrome seal. No substitution without spec revision.`

**Right -- Non-Chrome Seal (Industry Standard):** Emerald accent. Badge: `COMPLIANT`. Zr/Ti oxide, silane, organic polymer. Good to excellent performance. Automotive OEMs fully transitioned. Bottom: `Automotive OEMs have fully transitioned. Military is following, but slower.`

## Phase 7 -- MIL-DTL-16232 + Defects

Y: 26.5" to 32.5". Two-column.

**Left -- MIL-DTL-16232 Classification:**

| | Type M (Mn) | Type Z (Zn) | Type ZM (Zn-Mn) |
|---|---|---|---|
| Class 1 | Oil preservative | Oil preservative | Oil preservative |
| Class 2 | CrO3 seal | CrO3 seal | CrO3 seal |
| Class 3 | Resin coated | Resin coated | Resin coated |
| Class 4 | As deposited | As deposited | As deposited |

Note: `This poster covers Type Z and Type ZM. Type M = manganese phosphate (CC-03).`

**Right -- Post-Treatment Defects:** White efflorescence, seal not adhering, water spots, paint blistering, mud cracking.
