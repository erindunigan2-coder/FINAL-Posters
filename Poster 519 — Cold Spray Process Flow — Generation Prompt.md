## Phase 6 -- Why Cold Spray? Comparison

Y: 22.5" to 28.5". Section label: `WHY COLD SPRAY? -- VS. CONVENTIONAL THERMAL SPRAY`.

**Left -- Cold Spray (W: 11.0", accent `#2EC4B6`):**
Subtitle: `Solid-State Revolution`.

| Property | Value |
|---|---|
| Particle state | SOLID -- no melting |
| Oxidation | ZERO |
| Residual stress | Compressive (beneficial) |
| Phase change | None -- feedstock = coating |
| Porosity | < 1% (Cu < 0.5%) |
| Heat-affected zone | None |
| Substrate heating | Minimal -- spray polymers & composites |
| Materials | Ductile metals: Cu, Al, Ti, Ni, Ag |
| Fume generation | Minimal |
| Thickness limit | Virtually unlimited |

Bottom: `The only thermal spray that preserves feedstock properties -- no oxide, no decomposition` in `#2EC4B6`.

**Right -- Conventional (W: 11.5", accent `#E8A020`):**
Subtitle: `Melt-and-Splat`.

| Property | Value |
|---|---|
| Particle state | Molten or semi-molten |
| Oxidation | Significant |
| Residual stress | Tensile (can cause cracking) |
| Phase change | Common |
| Porosity | 0.5--15% |
| Heat-affected zone | Yes |
| Substrate heating | Significant |
| Materials | Metals, ceramics, cermets |
| Fume generation | High |
| Thickness limit | Typically < 2 mm |

Bottom: `Broader material range but thermal damage is inherent` in `#E8A020`.

## Phase 7 -- Troubleshooting Quick Hits + Footer

**Troubleshooting (Y: 28.5"--32.5"):** Section label: `QUICK TROUBLESHOOTING -- 4 COMMON PROBLEMS`. Four coral-accented cards:

| Problem | Cause | Fix |
|---|---|---|
| LOW DEPOSITION EFFICIENCY | Velocity below critical threshold | Increase gas pressure or temperature; verify powder size |
| POOR ADHESION | Surface contamination or insufficient profile | Re-blast; verify water-break-free; reduce time to spray |
| POROSITY IN DEPOSIT | Velocity too low or wrong powder morphology | Increase pressure; use spherical gas-atomized powder |
| NOZZLE CLOGGING | Powder buildup on throat (Al, Cu) | Clean nozzle; reduce gas temp; use WC-Co throat |
