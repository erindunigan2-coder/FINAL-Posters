**Full Parameter Table (Y: 3.8"-11.0"):**

| Parameter | Range | Notes |
|---|---|---|
| Oxygen pressure | 20-40 PSI | Adjust for neutral or slightly oxidizing flame |
| Fuel pressure (acetylene) | 10-15 PSI | Neutral flame preferred; NEVER exceed 15 PSI |
| Fuel pressure (propane) | 10-20 PSI | Alternative; lower flame temp (~2800 degC) |
| Compressed air pressure | 40-80 PSI | Higher = finer droplets, more overspray |
| Wire feed rate | 1-8 m/min | Material and diameter dependent |
| Flame temperature | ~3100 degC (oxy-acet); ~2800 degC (oxy-propane) | Oxy-acetylene is standard |
| Particle velocity | 80-200 m/s | Lower end of thermal spray range |
| Standoff distance | 150-250 mm (6-10 inches) | Manual control; maintain consistent |
| Spray angle | 60-90 degrees | Perpendicular preferred |
| Deposition rate | 2-8 kg/hr | Wire material and diameter dependent |
| Deposition efficiency | 50-70% | Remainder is overspray |

Header fill `#3A4055`. Data: JetBrains Mono 12pt.

**Flame Type Guide (Y: 11.5"-15.3"):** Three side-by-side panels.

| Flame Type | O2/Fuel Ratio | Appearance | Use |
|---|---|---|---|
| Neutral (accent `#27AE60`, `RECOMMENDED DEFAULT` badge) | Balanced | Clear inner cone; no feather | DEFAULT -- zinc, aluminum, most materials |
| Oxidizing (accent `#E8A020`) | Excess O2 | Short, pointed inner cone; hissing | Some bronzes; avoid for zinc |

## Phase 6 -- Manual Technique + Preheat + Problems

### Operator-Controlled Variables (Y: 22.0"-28.5", left W: 11.0")

Section label: `OPERATOR-CONTROLLED VARIABLES`.

Title: `MANUAL TECHNIQUE` accent `#E8A020`.

| Variable | Guidance |
|---|---|
| Traverse speed | Steady, consistent; 200-600 mm/s typical |
| Spray pattern | Crossing passes at 60-90 deg to each other |
| Overlap | 50% between passes for uniform thickness |
| Spray angle | 75-90 deg; below 45 deg causes porosity |
| Number of passes | Build to spec in multiple thin passes |
| Standoff consistency | 150-250 mm -- arm distance, not wrist |

Note: `Consistent traverse speed and standoff are the hardest things to maintain. Practice on scrap before production.`

### Substrate Preheat (right W: 11.5")

Title: `SUBSTRATE PREHEAT` accent `#27AE60`.
- Preheat to 80-120 degC using flame gun (no wire feed)
- Drives off moisture; improves first-pass adhesion
- Temperature-indicating crayons or IR thermometer to verify
- Do NOT overheat -- aluminum substrates max 120-150 degC
- Preheat immediately before spraying

Callout: `Preheat is optional for some specifications but ALWAYS improves bond quality. Make it standard practice.`

### Parameter Problems (Y: 28.5"-32.5")

Section label: `PARAMETER PROBLEMS -- 4 COMMON ISSUES`. Four cards, left accent `#E05C5C`.

| Problem | Cause | Fix |
|---|---|---|
| WIRE NOT MELTING FULLY | Flame too lean; wire feed too fast | Enrich flame; reduce wire feed; verify neutral |
| EXCESSIVE SPATTER | Wire feed too fast for flame; air too high | Reduce wire feed; balance air; check for kinks |
| OXIDIZED COATING | Oxidizing flame; standoff too far | Adjust to neutral; reduce standoff |
| INCONSISTENT THICKNESS | Varying traverse speed; changing standoff | Practice consistent technique; use guide rails |
