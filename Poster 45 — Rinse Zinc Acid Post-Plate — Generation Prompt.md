Title: `PROPER POST-PLATE RINSE` `#27AE60`.

1. Parts exit zinc bath -- acidic, chloride on surface
2. Double counterflow rinse, 30--60 sec/stage -- chloride diluting

## Phase 5 -- Parameters + Drag-Out

Y: 14.5" to 21.5". Section: `POST-PLATE RINSE PARAMETERS`.

**Left -- Parameter Table (X: 0.5", W: 14.0"):**

| Parameter | Value |
|---|---|
| Water type | DI strongly recommended |
| Temperature | Ambient |
| Stages | 2--3 stage counterflow minimum |
| First tank | Optional drag-out recovery (return to plating bath) |
| Flow rate | 3--5 gal/min per stage |
| Immersion time | 30--60 sec per stage |
| Agitation | Air + part movement (both) |
| Conductivity target | < 100 uS/cm at final stage |
| Optional bright dip | 0.1--0.5% HNO3 or HCl before passivation |

**Right -- Drag-Out Economics (X: 15.0", W: 8.5"):**
Title: `DRAG-OUT ECONOMICS` `#E8A020`.
- Zinc bath drag-out: ~1--3 gal per 1000 ft2
- Bath chloride concentration: ~200 g/L KCl
- Each rack carries ~50--150 mL of bath solution
- That's 10--30 g chloride per rack into the rinse
- Drag-out recovery tank can return 50--70% of chemistry

Tip: `Air knives or spray bars at zinc tank exit cut drag-out volume by 30--50%.` `#27AE60`

## Phase 6 -- Common Problems

Y: 21.5" to 27.5". Section: `WHAT GOES WRONG AT THE POST-PLATE RINSE`.

| Problem | Symptom | Cause | Fix |
|---|---|---|---|
| Passivate degradation | Short bath life, frequent replenishment | Chloride drag-in | Add rinse stages; drag-out recovery tank |
| Uneven passivate color | Patchy or mottled chromate | Localized chloride residue | Extend rinse; air agitation; spray nozzles |
| White haze on zinc | Cloudy surface before passivation | Zinc hydroxide or chloride salt residue | Thorough rinsing; check water quality |
| Passivate pH dropping | Must add alkali constantly | Acidic drag-out from zinc bath | Improve rinse; monitor final rinse pH |
| Water spots | Marks after drying | Hard water in rinse | Use DI for final rinse stage |

## Phase 7 -- Monitoring + Safety

Y: 27.5" to 32.5".

**Left -- Monitoring (X: 0.5", W: 11.0"):**
Title: `CRITICAL MONITORING` `#2EC4B6`.
- Conductivity: check EVERY HOUR -- tightest target on the line (< 100 uS/cm)
- Chloride test: silver nitrate spot test on rinse water
- Passivate bath life: if dropping, the rinse is failing
- Dump schedule: when conductivity > 300 uS/cm
- Bright dip (if used): check concentration daily

**Right -- Safety (X: 12.0", W: 11.5"):**
Title: `SAFETY -- ACID RINSE WATER` `#E8A020`.
- Rinse water is acidic (pH 3--5) from zinc bath drag-out
- Contains dissolved zinc chloride -- skin and eye irritant
- All overflow to waste treatment -- zinc is regulated discharge
- Bright dip (HNO3): corrosive -- handle as acid
- Standard PPE: goggles, gloves, apron
